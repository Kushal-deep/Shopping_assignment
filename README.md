🛒 React Shopping Cart App

A modern e-commerce shopping cart application built with React, Vite, and Tailwind CSS, featuring product listing, product details, cart management, filters, and search functionality. Fully responsive and interactive.

[Live Demo](https://shopping-cart-omega-lemon.vercel.app/?price=50000)

## Features
- Responsive product listing with grid layout  
- Category and price filters  
- Search functionality  
- Product detail page with image carousel and quantity selector  
- Cart management (add/remove/update quantity)   
- Persistent cart state using **React Context** and `localStorage`   
- Fully responsive design for mobile, tablet, and desktop  
- Modern UI with **Tailwind CSS** and **Lucide icons**  
- Smooth animations using **Framer Motion**

## Technologies Used
- **React.js** (Functional Components & Hooks)  
- **Vite** (Fast development setup)  
- **Tailwind CSS** (UI styling & responsive design)  
- **React Router DOM** (Dynamic routing for product pages)  
- **Lucide React** (Icons)  
- **Framer Motion** (Animations)  
- **React Context** (Cart & wishlist state management)


## Getting Started

### Prerequisites
- Node.js >= 18.x  
- npm or yarn  

### Installation
```bash
git clone https://github.com/Kushal-deep/Shopping_assignment.git
cd Shopping_assignment
npm install
npm run dev


### Usage

1.Browse products on the homepage
2.Use filters and search to find products
3.Click a product to see its details
4.Add items to the cart and manage quantities
5.Checkout to simulate an order
